## 我在做什麼

我是 Design Lead，也做 PM，會寫 TypeScript。工作的重心是**把問題解清楚**：複雜通常不是功能太多，而是問題沒被講明白。

最近花最多時間的是 **AI 協作流程**：讓 AI 不只是會寫程式，而是能被控制、能被信任、做錯了能回復。

## 我怎麼想事情

- **簡約是手段，使用者的思維才是目的。** 複雜，通常代表問題還沒解清楚。
- **AI 是新材料。** 難題不在它多會寫，而在控制感、不確定性怎麼處理，以及出錯後能不能回復。
- **可逆的事快做快改，不可逆的事用完整框架評估。**
